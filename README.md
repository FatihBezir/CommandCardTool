# CommandCardTool

## Türkçe

CommandCardTool, Command & Conquer: Generals Zero Hour için hazırlanmış komut kartı ve hotkey düzenleme aracıdır. Amaç, önceden ayarlanmış hotkey paketleri kullansanız bile, örneğin FAS, xezon, Exile veya benzeri hazır profillerdeki kısayolları daha rahat düzenleyebilmenizi sağlamaktır.

Normalde hotkey değişiklikleri farklı BIG/INI/CSF dosyalarına dağılmış olabilir ve bazı kısayollar yalnızca yazı olarak değil, oyun içindeki komut eşleşmeleri üzerinden de çalışır. Bu araç, bunları daha anlaşılır bir arayüzde toplamayı hedefler.

### Özellikler

- Hazır hotkey profilleri kullanırken bile komut kartı kısayollarını arayüzden düzenleyebilirsiniz.
- Komut kartındaki buton yazılarında görünen hotkey harflerini değiştirebilirsiniz.
- Hotkey değiştiğinde ilgili kısa yol harfi buton resminin üzerine işlenebilir.
- Toplu olarak komut kartı slotlarına harf atayabilir ve bu harfleri buton görsellerine uygulayabilirsiniz.
- General Powers tarafındaki bazı özel kısayol etiketleri de senkronize edilir, böylece yalnızca görünen yazı değil oyunun kullandığı shortcut label da güncellenir.
- Extra Settings bölümünden `Select all units`, `Select aircraft`, `Select matching units`, `Scatter`, `Stop`, `Select hero`, `View command center` ve `Create formation` gibi oyun içi CommandMap tuşları düzenlenebilir.
- Beacon ve boştaki worker seçme gibi ek kısayollar da değiştirilebilir.
- Aynı tuş kombinasyonunun birden fazla komuta atanmasını engelleyen basit bir çakışma kontrolü vardır.

### Notlar

Bu araç hâlâ geliştirme ve test aşamasındadır. Tüm birimler, tüm generaller ve tüm özel durumlar eksiksiz test edilmemiş olabilir. Bazı birimlerde eksik slot, yanlış ikon, yanlış hotkey eşleşmesi veya farklı mod/hotkey paketlerinden gelen uyumsuzluklar görülebilir.

Bir sorun fark ederseniz, hangi general, birim, slot veya hotkey profilinde olduğunu belirterek raporlamak düzeltmeyi kolaylaştırır.

## English

CommandCardTool is a command card and hotkey editing utility for Command & Conquer: Generals Zero Hour. It is designed to make hotkey customization easier even when you are already using predefined hotkey packs, such as FAS, xezon, Exile, or similar ready-made profiles.

In Zero Hour, hotkey behavior can be spread across BIG, INI, and CSF files. Some shortcuts are not controlled only by visible text labels; they may also depend on command map entries or special shortcut labels. This tool aims to bring those edits into a clearer user interface.

### Features

- Edit command card hotkeys through a UI, even on top of existing hotkey profiles.
- Change the hotkey letters shown in command card labels.
- Paint the selected shortcut letter directly onto the related button image.
- Apply hotkey letters in bulk across command card slots and button images.
- Sync special General Powers shortcut labels, so both the displayed label and the in-game shortcut label can use the same key.
- Change gameplay CommandMap keys from Extra Settings, including `Select all units`, `Select aircraft`, `Select matching units`, `Scatter`, `Stop`, `Select hero`, `View command center`, and `Create formation`.
- Change extra shortcuts such as beacon placement and selecting the next idle worker.
- Prevent duplicate key combinations with a simple conflict check before saving.

### Notes

This tool is still in development and has not been fully tested across every unit, general, and edge case. Some units may be missing, some slots may be wrong, and some icons or hotkey mappings may still need correction, especially when used with different mods or hotkey packs.

If you find an issue, please include the general, unit, slot, and hotkey profile involved so it can be fixed more easily.
